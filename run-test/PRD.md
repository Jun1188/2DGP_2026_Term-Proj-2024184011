# pico2d run-test 요구사항

2026-11-10. 기존 HTML 1.7 기획의 주요 규칙을 Python/pico2d에서 시험하고, 레이어별·기능별·단계별·라운드별 진단을 독립 제공한다. 정식 배포본은 아니다.

## 산출물

- main.py: pico2d 실행, 장면·시드·글꼴 선택.
- engine.py: 화면/SDL과 독립된 게임 규칙, 복사 상태 예측과 revision 기반 확정.
- app.py: 보드·경로 선택·드로우·손패·전투 결과·상점·수치/위치 편집·점수 효과.
- scenes.py: 요소별 재현 장면과 데이터 기반 목록.
- view_model.py: 7개 렌더링 레이어의 데이터 분리.
- diagnose.py + tests/: 4분류 선택, 레이어/라운드 개별 선택, JSON 결과, 별도 시각 진단 및 적 턴/마스터 개별 단계 실행.
- game-data.json: 원본 1.7 스냅샷. assets/: 점수 효과, 문양 덱 뒷면, 기본·표시 윷, 말·수문장 전투 초상.
- README.md / DIAGNOSTICS.md: 실행/진단/제약/사용자 확인 방법.

2026-11-13에 Windows pico2d 창에서 오른쪽 아래 덱을 클릭해 첫 세 턴을 플레이했다. 5번 업기, C로 가는 갈림길 선택, 생존한 수문장과의 제자리 재교전까지 확인했다. 단위 테스트 36건이 통과했다. [플레이 결과와 화면](../docs/yutochess-revised-design.md#첫-3턴-실행-기록)

2026-11-14에 기본 시드 실제 런을 같은 입력으로 재현했다. 정산·상점·다음 손패 회귀 검사를 포함해 단위 테스트 37건이 통과했다. [1라운드 플레이 기록](../docs/yutochess-revised-design.md#실제-런-1라운드-완주-기록)

## 사용자 확인

README의 명령으로 창을 연다. 드로우/선택, 갈림길 보드 동시 표시, 특수칸 5종, 시야 경계 3칸, 고정 대상 추적, 선공/반격, 일반/빅 9라운드, 매턴 +/- 및 이미지 효과, 상점·다음 라운드를 확인한다. 진단 명령은 DIAGNOSTICS.md를 따른다. 동작 줄이기와 각 레이어 OFF도 확인한다.

## 차이

브라우저 화면 복제나 HTML 래퍼가 아니다. Python 규칙 구현과 자체 pico2d UI다. HTML과 대조한 범위는 업기 체험의 첫 세 턴과 기본 시드 1-1 완주, 보상 수령, 상점 덱 교체, 1-2 첫 투척이다. 임의 UI 좌표 편집과 JSON 불러오기는 제공하지 않는다. 정식 에셋·사운드·무한 모드·PvP·제출 자동화는 범위 밖이다. 한글 글꼴과 pico2d는 사용자 환경에 필요하다.

## 개별 점수 변동 강조 (2026-11-11)

특수칸·전투·업기 등을 포함한 각 feedback의 0이 아닌 변화량마다 점수판 테두리·숫자·출처/부호·이미지 효과를 순서대로 재생한다. 같은 행동의 +와 -가 상쇄돼도 각 변동을 표시한다. 완주 정산은 metric=settled 기록으로 완주 점수판을 강조하고, 다른 기록은 보유점수판을 강조한다. +0은 기존 내역에만 남긴다. 장면·라운드 변경과 수치 편집은 강조 상태를 초기화한다. 이미지 OFF에서도 숫자 강조는 유지하고, 동작 줄이기는 모션을 생략한다.

사용자 확인: 일반 칸 +/-, 특수칸 5종, 업기, 전투 보상/말 사망, 판 전체/빅 기믹, 완주 정산, 합계 상쇄, 연속 행동을 실행한다. 각 출처·부호와 해당 점수판 강조, 장면 전환 초기화, 효과/동작 줄이기/레이어 토글을 확인한다. 실행·테스트는 사용자에게 맡긴다.
