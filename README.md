## 상세 기획서 · 플레이 가능한 박싱

[상세 기획서](docs/detailed-design/index.html#boxing)를 브라우저로 열면 메뉴·덱 선택 → 라운드 특성 → PvE → 보상 → 상점·덱 편집 → 다음 라운드를 직접 플레이할 수 있습니다. 3막 9라운드 후 결과·재시작으로 이어집니다.

편집 모드에서 UI 프레임, 보드·특수칸, 말·보스 배치/능력치/이동속도, 마스터와 라운드 자원을 바꾸고 같은 장면을 플레이합니다. 장면 JSON 저장·불러오기와 고정 투척도 제공합니다.

[실행·조작·사용자 확인 절차](docs/detailed-design/README.md) · [요구사항](PRD.md). HTML 박싱과 Python/pico2d 구현은 별도이며 이번 작성 후 빌드와 테스트는 실행하지 않았습니다.

1.5 개정은 weight 점수 폭발과 HP·공격 성장의 분리·연동, 리스크 픽에 따른 수문장·추가 보스, 게임 마스터의 특수칸/판 전체 특성, 상점 성장과 출전 윷 편집을 포함합니다. 바로 시작은 기본값으로 즉시 출전합니다. 선택형 첫 3턴 체험은 도→걸→모 고정이며 실제 난수 런과 구분합니다. 투척 뒤에는 바로 이동하고 실제 갈림길만 선택합니다. HP 박스·타격 전투 결과는 계속 버튼까지 유지하며 완주 관문은 정사각형 모서리 아래 G→END로 연결합니다. 3·3·3(3초 이름·30분 플레이·종료 3시간 내 회상)은 설계 기준이며 사용자 확인 전입니다.
