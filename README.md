## 상세 기획서 · 플레이 가능한 박싱

[상세 기획서](docs/detailed-design/index.html#boxing)를 브라우저로 열면 메뉴·덱 선택 → 라운드 특성 → PvE → 보상 → 상점·덱 편집 → 다음 라운드를 직접 플레이할 수 있습니다. 1막 3라운드 후 결과·재시작으로 이어집니다.

편집 모드에서 UI 프레임, 보드 좌표, 말·수문장 배치/능력치, 라운드 자원을 바꾸고 같은 장면을 플레이합니다. 장면 JSON 저장·불러오기와 고정 투척도 제공합니다.

[실행·조작·사용자 확인 절차](docs/detailed-design/README.md) · [요구사항](PRD.md). HTML 박싱과 Python/pico2d 구현은 별도이며 이번 작성 후 빌드와 테스트는 실행하지 않았습니다.
