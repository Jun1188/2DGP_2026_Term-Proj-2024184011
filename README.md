## 상세 기획서 · 플레이 가능한 박싱

[상세 기획서](docs/detailed-design/index.html#boxing)를 브라우저로 열면 메뉴·덱 선택 → 라운드 특성 → PvE → 보상 → 상점·덱 편집 → 다음 라운드를 직접 플레이할 수 있습니다. 3막 9라운드 후 결과·재시작으로 이어집니다.

편집 모드에서 UI 프레임, 보드·특수칸, 말·보스 배치/능력치/이동속도, 마스터와 라운드 자원을 바꾸고 같은 장면을 플레이합니다. 장면 JSON 저장·불러오기와 고정 투척도 제공합니다.

[실행·조작·사용자 확인 절차](docs/detailed-design/README.md) · [요구사항](PRD.md). HTML 박싱과 Python/pico2d 구현은 별도이며 이번 작성 후 빌드와 테스트는 실행하지 않았습니다.

1.5 개정은 weight 점수 폭발과 HP·공격 성장의 분리·연동, 리스크 픽에 따른 수문장·추가 보스, 게임 마스터의 특수칸/판 전체 특성, 상점 성장과 출전 윷 편집을 포함합니다. 바로 시작은 기본값으로 즉시 출전합니다. 선택형 첫 3턴 체험은 도→걸→모 고정이며 실제 난수 런과 구분합니다. 투척 뒤에는 바로 이동하고 실제 갈림길만 선택합니다. HP 박스·타격 전투 결과는 계속 버튼까지 유지하며 완주 관문은 정사각형 모서리 아래 G→END로 연결합니다. 3·3·3(3초 이름·30분 플레이·종료 3시간 내 회상)은 설계 기준이며 사용자 확인 전입니다.


## 1.6 추가 수정 (2026-11-10)

수문장 옆 출발 0에서 코스를 돌아 귀환 J를 거친 뒤 G로 진입한다. 출발 대기 말도 표시하며, 미출발 말을 귀환 말이 업어 완주하지 않게 논리 위치를 구분한다. 기본 방향·후보 원·순번은 표시하지 않는다. 다음 칸 예측은 상단 토글로 열고 후보 하나씩 비교한다. 경로는 호버/명시적 경로 보기에서만 점선과 최종 화살촉 하나로 표시한다.

수문장 weight·공격과 라운드 성장 계수를 높였다. 지름길 단독 선공 ×0.6 / 업기 선공 ×1.25, G 받는 피해 ×0.75 / 절반 HP 반격 ×1.5다. 첫 라운드는 일반 보스 0체, 둘째부터 기본 일반 보스+리스크 픽 추가다. 실제 난도는 사용자 확인 전이다.

라운드 결과 → 다음으로(보상 1회) → 상점 / 추가 이자 선택으로 진행한다. 추가 이자는 상점을 건너뛰고 보상 후 잔액 기준 이자를 추가 1회 받는다. 마지막 라운드는 런 결과로 간다. 상점 상단은 현재 금액·다음 라운드 예상 이자만 표시한다. 윷 구매·덱 편집과 특성 구매를 분리하고 윷 강화는 덱 편집 토글 안 아래, 말 강화·특성은 각 말 카드에 둔다. 말·윷·특성의 고정 SVG 아이콘과 복합 효과 조합을 제공한다.

[박싱 안내](docs/detailed-design/README.md)의 1.6 사용자 확인 항목을 따른다. 빌드·실행·테스트는 사용자에게 맡긴다.


## 손패 직접 선택과 수치 편집 (2026-11-10)

매턴 드로우→새 윷 공개→직접 4개 선택→투척→사용 윷 반환·셔플을 차례로 보여준다. 자동 선택과 접힌 손패 선택을 제거했다. 사용하지 않은 손패는 유지하고 다음 턴 부족한 수만 보충한다. 교체도 반환→드로우→공개→선택을 거친다.

편집기는 기본 weight·HP·공격과 추가 HP/공격 배율만 입력한다. 현재 HP·최대 HP·공격은 읽기 전용 결과이며 적용 예정 수치와 실제 적용을 같은 계산으로 처리한다. 받은 피해량을 보존하고, 추가 배율은 윷 자동 배율 갱신과 분리해 유지한다. 보스 위험도는 기본값·weight와 중복 적용하지 않고 HP/공격 자동 배율에 각 1회 반영한다. 빌드·테스트는 사용자에게 맡긴다.

덱·손패·던지기는 보드 아래 하단 조작 영역에 둔다. 드로우 시 덱에서 손패로 이동하는 모션 후 공개하며 사용할 윷은 손패 내 강조+12px 올림으로 표시한다. 별도 사용 슬롯은 없고 4개 선택 제한·재클릭 해제를 지원한다.

2026-11-10 추가: 다음 칸 예측은 보드 상단 토글로 열고 보드 옆 상단에 후보 하나만 Previous / Next로 넘긴다. 하단 덱·손패·버튼은 내부 스크롤이나 드래그 없이 줄바꿈해 전부 표시한다. 후보 넘기기는 경로를 자동 표시하거나 게임 상태·난수를 변경하지 않는다.



## 1.7 추가 규칙 (2026-11-10)

일반 보스는 플레이어 행동 뒤 별도 턴을 갖는다. 지름길 C·완주 관문 G 수문장은 고정한다. 탐지는 연결된 보드 경로의 최단 거리로 판정하며 기본 시야는 3칸이다. 편집 모드에서 일반 보스를 선택해 시야를 0~30칸으로 바꾼다. 미출발·사망·완주 말은 탐지 대상에서 제외한다. 여러 말이 동시에 들어오면 ID 순으로 첫 말을 포착한다. 발견 뒤에는 시야를 벗어나도 같은 말을 추적하며 업기로 합류해도 추적 대상을 유지한다. 대상 사망·완주 시 다시 탐색한다.

발견한 일반 보스마다 공정한 윷 4개(표시 윷 1개 포함)를 1회 던진다. 플레이어 손패는 쓰지 않는다. 윷·모 추가 투척은 없다. 최단 경로로 결과만큼 접근하며 첫 아군 접촉 칸에서 정지한다. 다른 생존 보스 칸은 통과하지 않는다. 빽도는 이전 보스 이동 이력을 1칸 되짚고 이력이 없으면 대기한다. 보스 턴은 보스 선공 → 생존 말 반격이다. 사망·처치·추가 투척·성장 증폭은 공통 전투 계산으로 처리한다. 예측은 복사 상태의 난수만 소비하며 실제 난수는 이동 확정 시 한 번 반영한다.

각 막 마지막 **1-3·2-3·3-3을 빅 라운드**로 둔다. 일반/엘리트는 현재 외곽 20칸, 빅은 외곽 28칸이다. 확장 8칸은 x1~x8이며 대각선과 귀환/관문 연결도 같은 보드 데이터를 사용한다. 판 크기를 바꾸면 편집 좌표 범위와 장면 저장·복원도 함께 바뀐다.

| 막 | 첫 일반 | 둘째 일반/엘리트 | 빅 라운드 | 빅 전용 갱신 충격 |
|---|---|---|---|---|
| 1막 | 특수칸 2개 | 3개 | 확장판·5개 | 출전 말마다 HP -5 |
| 2막 | 3개 | 4개 | 확장판·6개 | 출전 말마다 HP -10 |
| 3막 | 4개 | 5개 | 확장판·7개 | 출전 말마다 HP -15 |

첫 라운드는 축복·샘만, 둘째는 통행세까지, 이후는 질주 계약·가시 보물까지 추가한다. 판 전체 특성의 종류도 단계적으로 넓힌다. 갱신 충격은 기본 3턴마다 마스터가 갱신할 때 적용하며 미출발·완주·사망 말은 제외한다. 편집기로 주기를 바꾸면 충격 주기도 함께 바뀐다. 실제 난도·세션 길이는 미검증이다.

**매 턴 점수 피드백:** 윷가락·일반 칸·특수칸·업기·전투·판 전체·완주 추가 성장의 변화량을 출처별 +/-와 합계로 표시한다. 일반 칸은 기본 +10이며 4·9·14·19·x2·x4·x6·x8은 -5다. 특수칸·생존 보스 칸과 출발/귀환/중앙/관문/완주 칸은 일반 칸 효과에서 제외한다. 회복처럼 weight 변화가 없는 효과는 +0과 HP 효과를 구분한다. 이동 연출 중에는 적용 예정, 확정 뒤에는 이번 턴 변화로 보인다. 보유 weight는 완주할 때만 목표 점수로 정산한다.

**점수판 애니메이션:** 보유점수·완주점수·남은 목표가 실제 바뀔 때만 숫자를 보간한다. 증가/감소 방향, 윷·일반/특수칸·업기·전투·완주 종류, 절대 변화량/기존 값 대비 변화율에 따른 3단계 강도를 적용한다. 전투는 짧은 좌우 반동, 특수칸은 기울임, 업기·완주는 확대를 강조한다. 부호·화살표·출처를 함께 보여 색에만 의존하지 않는다. 단순 카드 선택·화면 갱신으로 같은 애니메이션을 다시 시작하지 않는다. 동작 줄이기 설정에서는 움직임과 숫자 보간을 생략한다.

**경로 선택 UI:** 갈림길 선택 버튼을 하단 손패에서 분리해 보드 옆에 붙인다. 보드·윷 결과·도착점·칸 효과·보유점수/HP 예측을 같은 영역에서 읽는다. 좁은 화면은 축소한 보드 바로 아래에 경로 버튼 2개를 배치한다. 보드를 덮는 고정 레이어를 쓰지 않는다. 투척 뒤 갈림길이면 해당 영역으로 이동한다. 상단 다음 칸 토글과 단일 후보 Previous/Next, 하단 펼친 손패는 유지한다.

**전체 요소 체험:** 메뉴에서 전체 요소 체험 → 확인할 요소 → 선택한 장면 시작. 장면 전환은 별도 체험 런을 초기화한다. 일반 칸 +/- , 특수칸 5종, 보스 시야 밖 대기/최초 발견/지속 추적/접촉 전투 및 3종 보스, 모든 판 전체 특성·9라운드·윷 결과·리스크·시작 덱·구현된 상점 상품을 고를 수 있다. 업기 체험만 첫 3턴 도→걸→모, 다른 장면은 플레이어 도 고정이며 윷 결과 장면은 해당 결과를 고정한다. 3턴 이후 기본 업기 체험은 난수다. 일반 보스는 항상 난수다. 박싱 머신에서 플레이어 고정을 바꿀 수 있다. 후속 구현으로 표시한 기능은 체험 제공 범위에 포함하지 않는다.

기존 1.6 데이터 장면은 호환하지 않는다. 새 1.7 장면으로 저장한다. 빌드·브라우저 실행·자동/수동 테스트·검증기는 실행하지 않았다. 실행 확인은 사용자에게 맡긴다. 원격 업로드·Public 설정·원격 커밋 수·e-Class 제출은 이번 수정으로 확인되지 않는다.
