# 윷토체스 박싱 · 조작과 사용자 확인

**데이터 1.4.0-draft · 장면 형식 2 · 2026-11-09**

`index.html`을 직접 열고 목차에서 **박싱 게임 · 플레이 / 편집**으로 이동하세요. HTML에 데이터 사본이 있어 서버 없이 열 수 있습니다. 같은 폴더의 `boxing-core.js`, `boxing-game.js`, `design-view.js`, `boxing-game.css`가 필요합니다.

최신 JSON 원본으로 열려면 사용자가 저장소 루트에서 다음 명령을 실행할 수 있습니다.

```powershell
python -m http.server 8000 --directory docs/detailed-design
```

[박싱 열기](http://localhost:8000/index.html#boxing). 파일 직접 열기는 HTML 데이터 사본, 서버 열기는 `game-data.json`을 우선 사용합니다. JSON 수정 시 HTML의 `embeddedGameData`도 동기화해야 합니다.

## 먼저 한 수

메뉴의 **30초 첫 수 체험 · 도 확정**은 선택형 연습입니다. 윷 4개를 고르고 던진 뒤 **말 A**를 움직이세요. 작은 A가 큰 B에 올라가 weight와 HP·공격이 커집니다. 이 장면은 실제 난수 런과 구분합니다. **체험 종료 · 실제 런 시작**으로 넘어갈 수 있습니다.

실제 런은 다음 순서입니다.

1. 기본 덱으로 시작하거나 다른 시작 덱을 펼쳐 고릅니다. 덱 효과는 카드 1장입니다.
2. 제시된 리스크 3개 중 하나를 선택합니다. 첫 라운드는 정석·안전·질주로 제한합니다.
3. **매 라운드 직전** 보유함에서 출전 윷을 고릅니다. 시작 상한 8개, 최소 4개입니다.
4. 손패에서 4개를 골라 확률을 확인하고 던집니다. 사용한 윷은 덱으로 반환·셔플하고, 턴이 끝나면 손패를 채웁니다.
5. 말 버튼에 마우스를 올려 이동·업기·특수칸·전투·정산을 예측합니다. 미래 weight·정산 상세는 펼쳐서 볼 수 있고 전투 HP/피해는 바로 표시합니다. 말 선택 뒤 교전이 있으면 전투 확인에서 시작합니다. 연출은 생략할 수 있습니다.
6. 완주 정산이 목표를 넘으면 보상을 받습니다. 상점 상품 3개, 선택한 말 강화, 다음 출전으로 이어집니다. 상세 덱 편집·특성·재진열은 펼쳐서 봅니다.
7. 3막 9라운드 뒤 런 결과와 빌드를 저장하거나 같은 시드로 새 런을 시작합니다.

게임 영역에 포커스가 있을 때 `1~6`: 손패 선택, `Space`: 던지기, `R`: 교체입니다. 말 버튼은 Tab·Enter로 조작할 수 있습니다.

## 읽어야 할 숫자

- **현재 말 합계 weight:** 생존 미완주 말의 잠재 점수. 완주해야 실제 점수가 됩니다.
- **남은 필요 점수:** 목표에서 실제 완주 정산 점수를 뺀 값입니다.
- **HP·공격:** 기본 능력치 + weight 계수에 윷·특성·판 전체 배율을 적용합니다. HP가 0이거나 weight가 0이면 라운드에서 사망합니다.
- **속도:** 기본 1은 윷 결과 그대로입니다. 전진은 윷 이동 + 기본 속도 -1 + 말/판 전체 보너스입니다. 빽도는 -1 고정입니다.
- **재화·이번 이자·다음 기본 목표:** 지출과 저축, 다음 도전을 미리 비교하는 정보입니다. 보상 단계의 이자는 수령할 확정값입니다.

## 보스·특수칸·마스터

지름길 C와 완주 직전 G의 **수문장 2체**는 항상 있습니다. 리스크 픽과 라운드에 따라 일반 보스가 추가돼 총 2~5체가 됩니다. 픽에 따라 HP·공격·기믹·개수도 바뀝니다.

C는 최종 도착 칸이 일치할 때만 교전합니다. 경유하거나 옆 칸에 가도 싸우지 않습니다. G는 모든 경로가 멈추는 완주 관문으로, 보스를 돌파하면 정산합니다. 지름길 수문장은 업힌 묶음의 선공을 강화하고, 완주 수문장은 HP 절반 이하 반격이 강해집니다.

게임 마스터는 별개로 특수칸과 판 전체 특성을 관리합니다. 칸에 **최종 도착**하면 weight·HP·속도의 메리트/디메리트를 줍니다. 기본 3턴마다 위치·개수·종류·판 전체 특성을 바꿉니다. 현재 효과·남은 턴은 기본 화면에, 다음 배치는 펼친 예고에 있습니다.

첫 라운드는 축복·회복 2칸과 고요한 판입니다. 둘째 라운드부터 작은 weight 손실과 이동·공격 보상을 소개합니다. 이후 더 다양한 디메리트·기믹을 사용합니다.

| 특성 부류 | 영향 |
|---|---|
| 초기 리스크 픽 | 가장 큰 메리트·디메리트. 목표·보스 수/능력치/기믹·보상 변경 |
| 구매 덱 카드 | 이익 중심. 구매·삭제·강화, 재화/슬롯 비용 |
| 마스터 판 전체 특성 | 초기 픽보다 변화는 작고 구매 카드보다 직접 디메리트는 큼 |

## 편집과 저장

**편집 모드**는 턴 진행을 멈춥니다. 대상 목록 또는 보드에서 개체를 고른 뒤 **변경 적용**을 누릅니다. 보드·말·보스·특수칸 드래그도 지원합니다.

| 대상 | 편집 |
|---|---|
| UI 프레임 | 패널 너비·글자 크기·강조색 |
| 보드 | 시각 좌표. 경로 연결은 유지 |
| 말 | weight·HP·기본 HP/공격·weight 계수·윷 배율·기본 속도/이동 보너스·배치 |
| 말 원형 | 현재 말 편집에서 ‘이후 라운드 원형에도 반영’을 선택 |
| 보스 | 주둔 칸·weight·HP·기본 능력치·계수·배율 |
| 라운드 | 목표·정산 점수·투척·교체·재화·리스크 위험도 |
| 마스터 | 갱신 주기·현재 판 전체 특성 |
| 특수칸 | 추가·삭제·위치·종류 |

**박싱 머신**에서 레이어를 표시/숨김하거나 고정 투척·확인용 장면을 열 수 있습니다. 장면 버튼은 별도 새 런으로 시작합니다. 화면을 숨겨도 규칙 효과는 유지됩니다.

장면 저장은 시드·카드·성장·손패·보스·마스터 계획·특수칸·배치·사건을 JSON으로 다운로드합니다. 불러오면 편집 모드에서 복원하고 이어서 플레이할 수 있습니다. 저장소 파일을 직접 덮어쓰지 않습니다. 1.3의 장면 파일은 규칙이 달라 거부합니다.

## 사용자 확인 목록 — 실행하지 않음

이번 작업에서는 빌드·브라우저 실행·게임 플레이·자동/수동 테스트를 하지 않았습니다. 아래 항목은 사용자가 수행합니다.

| 확인 | 기대 결과 |
|---|---|
| 첫 수 체험 → 윷 4개 → A 이동 | 도 확정 연습 표시, 작은 A가 B에 합류하고 weight·HP·공격이 각각 식에 따라 증가 |
| 실제 런 시작 → 리스크 → 출전 윷 → 한 턴 | 첫 라운드 선택지·정보량이 작고 보너스 2칸만 소개 |
| C 경유/정확한 C 도착을 비교 | 경유는 교전 없음, 정확한 도착은 예측과 교전 |
| 보스 예측 장면 → 공격 확인 → 연출/생략 | 선공·기믹 반격·HP 전후·사망·증폭이 예측과 동일하며 확정은 한 번 |
| 두 수문장과 위험도 높은 픽 비교 | 수문장 유지, 일반 보스 수·HP·공격·기믹이 선택에 따라 변경 |
| 편집기로 속도 변경, 빽도 | 전진만 속도 보너스 반영, 빽도는 -1 |
| 특수칸 도착/경유 비교 | 도착만 weight·HP·이동 효과, 위험은 선택 전에 표시 |
| 3턴 갱신 전후, 판 전체 특성을 핏값의 행군으로 변경 | 위치·개수·종류/특성 변경, 턴말 말·보스 weight 감소와 이동/공격 증가. 정산 말 제외 |
| 같은 말의 미리보기를 반복한 뒤 확정 | 손패·난수·마스터 다음 계획 불변, 예측과 같은 결과 |
| 상점의 카드/윷/말 특성, 말 강화·출전 상한 확대 | 메타 성장이 다음 라운드 유지되고 출전 윷은 직전에 편집 |
| 사용 윷 반환·셔플 | 독립 버림 더미 없이 다음 손패에 다시 뽑힐 수 있음 |
| 보상·이자·다음 목표·마지막 투척·사망 | 보상 1회, 예상/확정 이자 구분, 완주 정산만 승리 판정, 미정산 weight 손실 |
| 장면 저장·다른 장면·복원 | 성장·선택지·상품·보스·마스터·손패·난수·배치 복원. 잘못된 JSON은 기존 상태 보존 |
| 3막 진행·승패 결과 | 빌드와 최고 증가/전투 기록, 같은 시드 재시작 |
| 3초 게임명 / 자발적 약 30분 / 종료 3시간 내 비유도 회상 | 3·3·3 달성 여부를 실제 사용자 기록으로 판단. 기능 작성과 구분 |

## 파일과 범위

- `index.html`: 기획서와 게임 임베딩, 직접 열기용 데이터 사본.
- `game-data.json`: 3종 특성·보스·마스터·특수칸·성장과 수식의 초깃값.
- `boxing-core.js`: 공통 점수·전투·턴말 예측/확정, 시드·덱·상점·성장.
- `boxing-game.js`: 실제 조작·HUD·연출·초반 노출·편집·장면 저장/복원.
- `design-view.js`: 기획서 표·보드·공통 코어 계산기.
- `boxing-game.css`: 박싱 레이어·전투·숫자 증폭·반응형 UI.

모든 수치는 미검증 초깃값입니다. 무한 모드·별도 막 증강·PvP·대규모 SRPG·Python/pico2d 이식과 실제 3·3·3 달성은 후속 범위입니다.
