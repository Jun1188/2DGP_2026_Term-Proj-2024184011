# 윷토체스 상세 기획서

1차 기획서(`../2dgp_1차기획서-제출용.pptx`)를 기준으로 규칙·수치·구현 설계를 채운 상세 기획서입니다.

| 파일 | 역할 |
| --- | --- |
| `index.html` | 상세 기획서 본문. 표·윷판·그래프·투척 계산기는 `game-data.json`을 읽어 그립니다. |
| `game-data.json` | 족보, 윷가락, 부적, 증강, 수문장, 라운드, 경제, 윷판 경로 데이터. 게임 코드도 이 파일을 그대로 읽는 것을 전제로 합니다. |
| `img/toss-screen-concept.png` | 1차 기획서 7장의 투척 화면 콘셉트 이미지. |

## 보는 법

브라우저는 `file://`에서 JSON 읽기를 막기 때문에 로컬 서버로 여는 것이 가장 편합니다.
혹은 vs code에서 열어주세요.

```bash
python -m http.server 8000 --directory docs/detailed-design
```

그다음 `http://localhost:8000`을 엽니다. 서버 없이 `index.html`을 바로 열면 페이지 상단에서 `game-data.json`을 직접 골라 불러올 수 있습니다.

## 수정 규칙

- 수치는 `game-data.json`만 고칩니다. HTML에 같은 숫자를 다시 적지 않습니다.
- 모든 수치는 플레이테스트 전 초깃값입니다.
- 확정한 결정은 `index.html`의 18장 "결정 사항"에 있습니다. 9장 콘텐츠 목록의 개별 항목과 모든 수치는 미확정입니다.
