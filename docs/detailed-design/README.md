## 첫 3턴과 실제 런

**바로 시작 · 기본 덱**은 기본 덱·정석·8개 출전 윷으로 바로 시작합니다. 첫 화면은 드로우 대기입니다. 손패 자동 선택은 없습니다. 다른 덱·초기 리스크·출전 구성은 메뉴의 설정을 펼쳐 선택할 수 있습니다. 이후 라운드는 리스크 선택 → 출전 윷 편집을 유지합니다.

**전체 요소 체험 · 장면 선택**에서 요소별 장면을 고릅니다. 기본 업기 장면은 첫 3턴 도→걸→모를 고정합니다. 실제 런과 분리합니다.

매 턴 **윷 드로우 → 덱에서 손패로 이동하는 모션·공개 → 직접 4개 선택 → 던지기**를 거칩니다. 체험도 이 순서를 생략하지 않습니다.

1. **도:** 준비한 윷을 던지면 작은 A가 큰 B에 자동 합류합니다. 보유점수와 업기 배율을 봅니다.
2. **걸:** 5번 갈림길에서만 길을 고릅니다. 지름길을 고르면 C의 수문장과 HP 전투가 시작됩니다.
3. **모:** 큰 이동·배율 증가를 봅니다. 생존 보스가 현재 칸에 있으면 재공격하고, 처치한 뒤에는 실제 갈림길만 고릅니다.

실제 런에서는 투척 면·손패·상품을 시드 난수로 판정합니다. 연습의 4턴부터도 시드 난수로 진행합니다.

- **던지기 전:** 윷 드로우 → 손패 공개 → 직접 4개 선택이 필수입니다. 손패 선택은 접혀 있지 않습니다. 4개를 고르기 전에는 던질 수 없습니다. 진행 말은 바꿀 수 있습니다.
- **반환:** 사용한 4개는 즉시 덱에 반환·셔플합니다. 안 쓴 손패는 남기고 다음 턴 부족한 수만 보충합니다. 교체도 드로우·공개를 다시 거칩니다.
- **던진 뒤:** 결과는 하나로 확정하고 자동 이동합니다. 매번 말 후보를 고르지 않습니다. 실제 갈림길에서만 현재 길/지름길을 선택합니다.
- **전투:** HP 박스·막대, 선공/반격 타격과 피해 숫자를 표시합니다. 결과는 **결과 확인 · 계속**까지 유지됩니다. 연출을 생략해도 결과는 남습니다.
- **성장:** N(기본점수) × M(배율) × X(추가배율)과 증가량을 크게 표시합니다. 말의 보유점수가 쌓여도 완주 전에는 목표 점수로 확정되지 않습니다.
- **다음 라운드:** 라운드 결과 → 다음으로 → 상점 / 추가 이자 선택 → 리스크 선택 → 출전 윷 편집입니다. 추가 이자는 상점 대신 보상 수령 후 잔액 기준 이자를 추가 1회 받습니다. 마지막 라운드는 런 결과로 갑니다.

게임 영역의 `Space`: 던지기, `1~6`: 던질 윷 변경, `R`: 선택 윷 교체입니다. 버튼은 Tab·Enter로 조작합니다. 전투의 Esc는 연출 중에는 결과로 이동하고, 결과에서는 계속합니다.

## 다음 칸·상점·아이콘

- 출발 0은 완주 수문장 옆입니다. 1번으로 나가 코스를 돌고 귀환 J를 거친 뒤 G로 갑니다. 빽도로 출발에 돌아와도 완주하지 않습니다. 미출발 말은 귀환 말에 자동 합류하지 않습니다.
- 기본 보드에는 방향 화살표·후보 원·이동 순번·파란 경로 강조가 없습니다. 기물은 현재 노드 중앙을 덮으며 이웃 노드를 가리지 않습니다. 전투 중에도 노드 옆으로 밀리지 않습니다.
- **보드 상단의 다음 칸 보기 토글**로 예측을 엽니다. 보드 옆 상단에 **후보 하나**만 표시하고 **Previous / Next**로 넘깁니다. 좁은 화면에서는 보드 위에 놓습니다. 넘기기만으로 화살표를 켜거나 이동하지 않습니다.
- 다음 칸 선택지에 커서를 올린 동안만 얇은 중립색 점선이 보입니다. **최종 도착 노드 앞의 화살촉 하나만** 표시하며 커서를 벗기면 지웁니다. 중간 노드 화살표·순번·도착 원은 없습니다.
- Tab으로 초점만 옮기거나 말을 선택하거나 자동 이동할 때는 화살표가 없습니다. 키보드 Enter·터치는 **경로 보기**를 명시적으로 실행하며, 다른 선택지로 초점을 옮기거나 **미리보기 지우기 / Esc**로 닫습니다. **이 길로 이동**은 별도 확정입니다.
- **보드 크게 보기**와 좁은 화면 좌우 스크롤, 칸·보스·특수칸 안내, 마스터 갱신 예고, 보드·버튼에서 Space 오투척 방지는 유지합니다.
- 상점 상단은 현재 금액·다음 라운드 예상 이자만 표시합니다. 윷 구매·덱 편집과 특성 구매 영역을 나눕니다.
- **덱 편집**을 펼치면 출전 구성 아래에 윷 강화·삭제·판매가 있습니다. 말 강화·특성 삭제는 각 말 카드에 있고, 말 특성 상품에는 적용할 A~D 버튼이 있습니다.
- 말 A~D는 원·마름모·삼각형·사각형입니다. 윷·특성 아이콘과 이름·툴팁을 함께 표시하고 복합 효과는 아이콘을 조합합니다.
- 수문장 weight는 C 900 / G 2,400, 일반 보스 500~850입니다. 라운드/픽 배율 전 값입니다. 지름길은 단독 선공 ×0.6, 업기 선공 ×1.25, G는 받는 피해 ×0.75와 절반 HP 반격 ×1.5입니다. 1-1 일반 보스 0체, 1-2부터 기본+픽 추가입니다. 균형은 미확인입니다.

## 읽어야 할 숫자

- **보유점수 · 말 합계:** 생존 미완주 말의 잠재 점수. 완주해야 실제 점수가 됩니다.
- **남은 필요 점수:** 목표에서 실제 완주 정산 점수를 뺀 값입니다.
- **HP·공격:** 기본 능력치 + weight 계수에 윷·특성·판 전체 배율을 적용합니다. HP가 0이거나 weight가 0이면 라운드에서 사망합니다.
- **속도:** 기본 1은 윷 결과 그대로입니다. 전진은 윷 이동 + 기본 속도 -1 + 말/판 전체 보너스입니다. 빽도는 -1 고정입니다.
- **재화·이번 이자·다음 기본 목표:** 지출과 저축, 다음 도전을 미리 비교하는 정보입니다. 보상 단계의 이자는 수령할 확정값입니다.

## 보스·특수칸·마스터

지름길 C와 완주 직전 G의 **수문장 2체**는 항상 있습니다. 리스크 픽과 라운드에 따라 일반 보스가 추가돼 총 2~5체가 됩니다. 픽에 따라 HP·공격·기믹·개수도 바뀝니다.

C는 최종 도착 칸이 일치할 때만 교전합니다. 경유하거나 옆 칸에 가도 싸우지 않습니다. 외곽·대각선은 정사각형 귀환 모서리 J에서 합류합니다. J는 출발 0과 같은 좌표의 별도 귀환 경로입니다. 아래로 J → G → END가 이어집니다. G는 모든 경로가 멈추는 완주 관문으로, 보스를 돌파하면 정산합니다. 지름길 수문장은 업힌 묶음의 선공을 강화하고, 완주 수문장은 HP 절반 이하 반격이 강해집니다.

게임 마스터는 별개로 특수칸과 판 전체 특성을 관리합니다. 칸에 **최종 도착**하면 weight·HP·속도의 메리트/디메리트를 줍니다. 기본 3턴마다 위치·개수·종류·판 전체 특성을 바꿉니다. 첫 3턴은 현재 판 전체 효과를 요약해 보이고 세부 내용은 접습니다. 이후 현재 효과·남은 턴은 기본 화면에, 다음 배치는 펼친 예고에 있습니다.

첫 라운드는 축복·회복 2칸과 고요한 판입니다. 둘째 라운드부터 작은 weight 손실과 이동·공격 보상을 소개합니다. 이후 더 다양한 디메리트·기믹을 사용합니다.

| 특성 부류 | 영향 |
|---|---|
| 초기 리스크 픽 | 가장 큰 메리트·디메리트. 목표·보스 수/능력치/기믹·보상 변경 |
| 구매 덱 카드 | 이익 중심. 구매·삭제·강화, 재화/슬롯 비용 |
| 마스터 판 전체 특성 | 초기 픽보다 변화는 작고 구매 카드보다 직접 디메리트는 큼 |

## 편집과 저장

**편집 모드**는 턴 진행을 멈춥니다. 대상 목록 또는 보드에서 개체를 고른 뒤 **변경 적용**을 누릅니다. 보드·말·보스·특수칸 드래그도 지원합니다.

| 대상 | 편집 |
|---|---|
| UI 프레임 | 패널 너비·글자 크기·강조색 |
| 보드 | 시각 좌표. 경로 연결은 유지 |
| 말 | 기본 weight/HP/공격·추가 HP/공격 배율·속도·배치. 현재 HP·최대 HP·공격은 결과 전용 |
| 말 원형 | 현재 말 편집에서 ‘이후 라운드 원형에도 반영’을 선택 |
| 보스 | 주둔 칸·기본 weight/HP/공격·추가 HP/공격 배율. 계수·윷/보스 배율·현재 수치는 결과 전용 |
| 라운드 | 목표·정산 점수·투척·교체·재화·리스크 위험도 |
| 마스터 | 갱신 주기·현재 판 전체 특성 |
| 특수칸 | 추가·삭제·위치·종류 |

**박싱 머신**에서 레이어를 표시/숨김하거나 고정 투척·확인용 장면을 열 수 있습니다. 장면 버튼은 별도 새 런으로 시작합니다. 화면을 숨겨도 규칙 효과는 유지됩니다.

장면 저장은 시드·카드·성장·손패·보스·마스터 계획·특수칸·배치·사건을 JSON으로 다운로드합니다. 불러오면 편집 모드에서 복원하고 이어서 플레이할 수 있습니다. 저장소 파일을 직접 덮어쓰지 않습니다. 1.6 이하의 장면 파일은 경로·규칙이 달라 거부합니다. 귀환 J는 출발 0의 좌표를 따릅니다. G·END는 아래쪽 별도 노드이며 좌표 Y는 7.3까지 편집할 수 있습니다.

## 사용자 확인 목록 — 실행하지 않음

이번 작업에서는 빌드·브라우저 실행·게임 플레이·자동/수동 테스트를 하지 않았습니다. 아래 항목은 사용자가 수행합니다.

| 확인 | 기대 결과 |
|---|---|
| 기본 덱 8개 출전 → 드로우 → 공개 | 첫 드로우 6개·더미 2개. 뒷면 카드가 덱에서 손패로 이동한 뒤 공개되며 선택 0/4 |
| 하단 손패·오른쪽 덱 확인 → 카드 선택/재클릭 | 선택 카드는 손패 안에서 12px 올라가며 강조. 4개 선택 시 나머지 비활성, 해제하면 다시 선택 가능. 별도 사용 슬롯 없음 |
| 모션 중 드로우·새 런·장면 불러오기 반복 / 동작 줄이기 | 중복 입력 없이 드로우 1회. 동작 줄이기에서는 모션 없이 같은 손패 공개 |
| 좁은 화면 하단 영역·손패 줄바꿈 | 내부 스크롤·드래그 없이 손패 전체·던지기/교체 버튼·덱을 펼치고 선택 카드 윗부분이 잘리지 않음 |
| 3개 선택 / 4개 선택 → 투척 | 3개에서는 던질 수 없음. 4개에서만 투척, 선택 자동 보충 없음 |
| 4개 투척·반환 → 다음 드로우 | 안 쓴 2개 유지, 더미 6개로 반환·셔플. 다음 드로우 4개 후 손패 6개·더미 2개 |
| 선택 윷 교체 → 드로우 → 공개 | 선택 윷 반환·셔플 후 교체 드로우를 명시적으로 진행하고 다시 직접 선택 |
| 새 런·첫 투척 전 A를 weight 100, 기본 HP 40/공격 8, 추가 HP/공격 배율 각각 2로 편집 | 고요한 판·윷 배율 1·말 특성 없음에서 적용 예정/적용 후 HP 130/130, 공격 52 (실행 전 기대값) |
| 보스 추가 HP 배율 변경 → 적용 예정 확인 → 변경 적용 | 현재/최대 HP·공격은 읽기 전용. 예정 수치와 적용 결과 일치, 기존 피해량 보존 |
| 말의 추가 HP/공격 배율 변경 → 투척 | 윷 자동 배율만 갱신되고 편집한 추가 배율은 유지 |
| 위험도 변경 전후 비교 | 기본값·weight·추가 배율 유지. 보스 HP/공격 자동 배율에 위험도를 각 1회 적용 |
| DRAW·REVEAL·SELECT 장면 저장/복원 | 드로우 더미·공개 여부·선택·난수 유지. 이전 자동 선택 장면은 공개 대기로 복원 |
| 기본 보드·투척 직후·말 선택·단순 Tab 초점 | 기본 방향 화살표·후보 원·이동 순번·강조 경로 없음 |

## 수치 편집의 기준

기본 weight·HP·공격과 추가 HP/공격 배율만 입력합니다. HP·공격 계수와 윷/보스 자동 배율은 읽기 전용입니다. 적용 예정 현재 HP·최대 HP·공격은 실제 적용과 같은 계산을 사용합니다. 최대 HP가 줄어도 받은 피해량을 보존하므로 HP가 0이면 사망할 수 있습니다. 사망 개체는 배율 변경만으로 부활하지 않습니다. 말의 원형 저장을 선택하면 기본값과 추가 배율이 다음 라운드에도 유지됩니다.

## 1.7 추가 규칙 (2026-11-10)

일반 보스는 플레이어 행동 뒤 별도 턴을 갖는다. 지름길 C·완주 관문 G 수문장은 고정한다. 탐지는 연결된 보드 경로의 최단 거리로 판정하며 기본 시야는 3칸이다. 편집 모드에서 일반 보스를 선택해 시야를 0~30칸으로 바꾼다. 미출발·사망·완주 말은 탐지 대상에서 제외한다. 여러 말이 동시에 들어오면 ID 순으로 첫 말을 포착한다. 발견 뒤에는 시야를 벗어나도 같은 말을 추적하며 업기로 합류해도 추적 대상을 유지한다. 대상 사망·완주 시 다시 탐색한다.

발견한 일반 보스마다 공정한 윷 4개(표시 윷 1개 포함)를 1회 던진다. 플레이어 손패는 쓰지 않는다. 윷·모 추가 투척은 없다. 최단 경로로 결과만큼 접근하며 첫 아군 접촉 칸에서 정지한다. 다른 생존 보스 칸은 통과하지 않는다. 빽도는 이전 보스 이동 이력을 1칸 되짚고 이력이 없으면 대기한다. 보스 턴은 보스 선공 → 생존 말 반격이다. 사망·처치·추가 투척·성장 증폭은 공통 전투 계산으로 처리한다. 예측은 복사 상태의 난수만 소비하며 실제 난수는 이동 확정 시 한 번 반영한다.

각 막 마지막 **1-3·2-3·3-3을 빅 라운드**로 둔다. 일반/엘리트는 현재 외곽 20칸, 빅은 외곽 28칸이다. 확장 8칸은 x1~x8이며 대각선과 귀환/관문 연결도 같은 보드 데이터를 사용한다. 판 크기를 바꾸면 편집 좌표 범위와 장면 저장·복원도 함께 바뀐다.

| 막 | 첫 일반 | 둘째 일반/엘리트 | 빅 라운드 | 빅 전용 갱신 충격 |
|---|---|---|---|---|
| 1막 | 특수칸 2개 | 3개 | 확장판·5개 | 출전 말마다 HP -5 |
| 2막 | 3개 | 4개 | 확장판·6개 | 출전 말마다 HP -10 |
| 3막 | 4개 | 5개 | 확장판·7개 | 출전 말마다 HP -15 |

첫 라운드는 축복·샘만, 둘째는 통행세까지, 이후는 질주 계약·가시 보물까지 추가한다. 판 전체 특성의 종류도 단계적으로 넓힌다. 갱신 충격은 기본 3턴마다 마스터가 갱신할 때 적용하며 미출발·완주·사망 말은 제외한다. 편집기로 주기를 바꾸면 충격 주기도 함께 바뀐다. 실제 난도·세션 길이는 미검증이다.

**매 턴 점수 피드백:** 윷가락·일반 칸·특수칸·업기·전투·판 전체·완주 추가 성장의 변화량을 출처별 +/-와 합계로 표시한다. 일반 칸은 기본 +10이며 4·9·14·19·x2·x4·x6·x8은 -5다. 특수칸·생존 보스 칸과 출발/귀환/중앙/관문/완주 칸은 일반 칸 효과에서 제외한다. 회복처럼 weight 변화가 없는 효과는 +0과 HP 효과를 구분한다. 이동 연출 중에는 적용 예정, 확정 뒤에는 이번 턴 변화로 보인다. 보유 weight는 완주할 때만 목표 점수로 정산한다.

**점수판 애니메이션:** 보유점수·완주점수·남은 목표가 실제 바뀔 때만 숫자를 보간한다. 증가/감소 방향, 윷·일반/특수칸·업기·전투·완주 종류, 절대 변화량/기존 값 대비 변화율에 따른 3단계 강도를 적용한다. 전투는 짧은 좌우 반동, 특수칸은 기울임, 업기·완주는 확대를 강조한다. 부호·화살표·출처를 함께 보여 색에만 의존하지 않는다. 단순 카드 선택·화면 갱신으로 같은 애니메이션을 다시 시작하지 않는다. 동작 줄이기 설정에서는 움직임과 숫자 보간을 생략한다.

**경로 선택 UI:** 갈림길 선택 버튼을 하단 손패에서 분리해 보드 옆에 붙인다. 보드·윷 결과·도착점·칸 효과·보유점수/HP 예측을 같은 영역에서 읽는다. 좁은 화면은 축소한 보드 바로 아래에 경로 버튼 2개를 배치한다. 보드를 덮는 고정 레이어를 쓰지 않는다. 투척 뒤 갈림길이면 해당 영역으로 이동한다. 상단 다음 칸 토글과 단일 후보 Previous/Next, 하단 펼친 손패는 유지한다.

**전체 요소 체험:** 메뉴에서 전체 요소 체험 → 확인할 요소 → 선택한 장면 시작. 장면 전환은 별도 체험 런을 초기화한다. 일반 칸 +/- , 특수칸 5종, 보스 시야 밖 대기/최초 발견/지속 추적/접촉 전투 및 3종 보스, 모든 판 전체 특성·9라운드·윷 결과·리스크·시작 덱·구현된 상점 상품을 고를 수 있다. 업기 체험만 첫 3턴 도→걸→모, 다른 장면은 플레이어 도 고정이며 윷 결과 장면은 해당 결과를 고정한다. 3턴 이후 기본 업기 체험은 난수다. 일반 보스는 항상 난수다. 박싱 머신에서 플레이어 고정을 바꿀 수 있다. 후속 구현으로 표시한 기능은 체험 제공 범위에 포함하지 않는다.

기존 1.6 데이터 장면은 호환하지 않는다. 새 1.7 장면으로 저장한다. 빌드·브라우저 실행·자동/수동 테스트·검증기는 실행하지 않았다. 실행 확인은 사용자에게 맡긴다. 원격 업로드·Public 설정·원격 커밋 수·e-Class 제출은 이번 수정으로 확인되지 않는다.


### 1.7 사용자 실행 확인 (미실행)

| 선택 장면 / 조작 | 기대 결과 |
|---|---|
| 일반 보스 → 시야 밖 대기 → 드로우·4개 선택·도 투척 | 대상 미발견, 보스 위치 유지 |
| 일반 보스 → 3칸 이내 최초 발견 → 같은 절차 | 첫 대상 표시 후 난수 윷 결과·경로·도착점 표시. 빽도 이력 없으면 대기 |
| 일반 보스 → 시야 밖에서도 같은 말 추적 | 시야 밖의 A 추적 유지. 편집기로 B를 더 가까이 두어도 A 유지 |
| 보스 대상을 다른 말에 업기 / 사망·완주 처리 | 업기는 대상 유지, 사망·완주는 다음 보스 턴에 시야 안에서 재탐색 |
| 일반 보스 → 접근·선공·반격 → 도 투척 | 보스가 접촉 후 선공, 살아 있는 말만 반격. HP 전후와 결과 확인 표시 |
| 편집 → 일반 보스 → 탐지 시야 0/3/6 적용 → 장면 저장·복원 | 변경 시야 유지. 기존 추적 대상에는 시야 변경으로 자동 해제되지 않음 |
| 모든 특수칸 → 각 장면에서 도 투척 | 5번 칸 효과 발동. 축복/통행세/샘/질주 계약/가시 보물의 weight·HP·속도 변화 |
| 일반 칸 + / - 장면에서 도 투척 | 일반 칸 +10 / -5를 윷가락 증가량과 구분해 표시 |
| 업기 장면 → 도 후 걸 → 갈림길 | 보드와 경로 버튼이 함께 보임. 호버는 경로만, 버튼은 이동 확정 |
| 1-3·2-3·3-3 → 3턴 진행 | 외곽 28칸·추가 x칸 경로. 특수칸 5/6/7개, 갱신 충격 HP 5/10/15 감소 |
| 1-1·1-2·2-1·2-2·3-1·3-2 비교 | 기존 20칸 유지. 특수칸 2/3/3/4/4/5개 |
| 상단 미리보기를 반복한 뒤 같은 행동 | 보스 투척·이동·전투 결과가 동일. 미리보기만으로 실제 난수 변경 없음 |
| 점수 변화 뒤 카드 선택·말 정보 열기 | 같은 점수 애니메이션 재시작 없음. 증가/감소·출처·강도 구분 |
| 동작 줄이기 켬 → 동일한 행동 | 이동·점수 튕김·숫자 보간 생략, 최종 숫자·부호·출처 유지 |
| 일반/확장판 저장 → 다른 크기 장면에서 불러오기 | 해당 판의 경로·좌표·시야·보스 이동 이력 복원. 잘못된 JSON 거부 |

위 목록은 사용자 실행용 절차다. 작성자가 실행한 결과가 아니다. 임시 산출물을 만들지 않았고 삭제한 파일은 없다.


### 임시 GPT 이미지 점수 효과 (2026-11-10)

서브에이전트가 내장 GPT 이미지 도구로 만든 투명 PNG `assets/temp-score-fx/score-burst.png`를 점수판에 연결했다. 정적 이미지를 코드로 확대·이동·페이드하며 증가/감소는 색과 방향, 큰 변화는 크기·재생 시간으로 구분한다. 숫자 뒤쪽의 점수판 영역 안에서만 표시한다. 이미지가 로드되지 않으면 기존 숫자 효과를 유지한다. 동작 줄이기 설정에서는 재생하지 않는다.

박싱 머신의 **임시 이미지 효과: 켜짐/꺼짐** 버튼으로 끌 수 있다. 이 설정은 현재 페이지에만 적용하며 장면 JSON에는 저장하지 않는다. 제작 프롬프트와 도구 정보는 [에셋 출처](assets/temp-score-fx/README.md)를 따른다. 이 PNG는 실행에 필요한 추가 파일이므로 문서 폴더 이동·업로드 시 함께 포함한다.

사용자 확인: 일반 칸 +/- 장면에서 숫자 가독성·영역 밖 겹침·방향/색 차이, 큰 점수 변화의 강도, 효과 끄기, 동작 줄이기에서 생략 여부를 확인한다. 브라우저·빌드·테스트·검증기는 실행하지 않았다.

### 점수 강조·경로 안내·첫 화면 (2026-11-11)

index를 열면 본문과 목차 맨 위에 게임 테스트베드가 나온다. 경로 보기는 파란색 4px 프레임·강조 배경·14px 글자와 굵은 경로선을 사용한다.

점수판은 확정된 개별 변동을 0.65초 간격으로 강조한다. 같은 행동에서 +와 -가 상쇄돼도 출처별 강조가 남는다. 완주 정산은 별도 기록으로 완주점수판을 강조하며 성장 합계에 중복 가산하지 않는다. 전투 결과창에도 점수판을 표시하고 결과 화면에서도 유지한다. 미리보기에는 강조를 실행하지 않고, 일반 화면 갱신은 현재 재생 시각을 이어간다. 새 장면·런·라운드는 이전 효과를 지운다.

사용자 확인 항목: 특수칸 5종·일반 칸 +/-·업기·전투 보상/말 사망·판 전체/빅 기믹·완주, 증가/감소 상쇄, 결과창 점수판, 경로 안내의 밝은/어두운 테마, 카드 선택 시 효과 재시작 여부, 동작 줄이기와 이미지 효과 OFF. 빌드·실행·테스트·검증기는 실행하지 않았다.
