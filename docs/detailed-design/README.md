# 윷토체스 박싱 · 조작과 사용자 확인

**데이터 1.5.0-draft · 장면 형식 2 · 2026-11-09**

`index.html`을 직접 열고 목차에서 **박싱 게임 · 플레이 / 편집**으로 이동하세요. HTML에 데이터 사본이 있어 서버 없이 열 수 있습니다. 같은 폴더의 `boxing-core.js`, `boxing-game.js`, `design-view.js`, `boxing-game.css`가 필요합니다.

최신 JSON 원본으로 열려면 사용자가 저장소 루트에서 다음 명령을 실행할 수 있습니다.

```powershell
python -m http.server 8000 --directory docs/detailed-design
```

[박싱 열기](http://localhost:8000/index.html#boxing). 파일 직접 열기는 HTML 데이터 사본, 서버 열기는 `game-data.json`을 우선 사용합니다. JSON 수정 시 HTML의 `embeddedGameData`도 동기화해야 합니다.

## 첫 3턴과 실제 런

**바로 시작 · 기본 덱**은 기본 덱·정석·8개 출전 윷으로 바로 시작합니다. 처음부터 4개 윷과 진행 말이 준비됩니다. 다른 덱·초기 리스크·출전 구성은 메뉴의 설정을 펼쳐 선택할 수 있습니다. 이후 라운드는 리스크 선택 → 출전 윷 편집을 유지합니다.

선택형 **첫 3턴 체험 · 도 → 걸 → 모**는 실제 런과 구분한 고정 연습입니다.

1. **도:** 던지기만 누르면 작은 A가 큰 B에 자동 합류합니다. 보유점수와 업기 배율을 봅니다.
2. **걸:** 5번 갈림길에서만 길을 고릅니다. 지름길을 고르면 C의 수문장과 HP 전투가 시작됩니다.
3. **모:** 큰 이동·배율 증가를 봅니다. 생존 보스가 현재 칸에 있으면 재공격하고, 처치한 뒤에는 실제 갈림길만 고릅니다.

실제 런에서는 투척 면·손패·상품을 시드 난수로 판정합니다. 연습의 4턴부터도 시드 난수로 진행합니다.

- **던지기 전:** 진행 말·윷은 기본값을 유지하거나 선택형 패널에서 바꿉니다.
- **던진 뒤:** 결과는 하나로 확정하고 자동 이동합니다. 매번 말 후보를 고르지 않습니다. 실제 갈림길에서만 현재 길/지름길을 선택합니다.
- **전투:** HP 박스·막대, 선공/반격 타격과 피해 숫자를 표시합니다. 결과는 **결과 확인 · 계속**까지 유지됩니다. 연출을 생략해도 결과는 남습니다.
- **성장:** N(기본점수) × M(배율) × X(추가배율)과 증가량을 크게 표시합니다. 말의 보유점수가 쌓여도 완주 전에는 목표 점수로 확정되지 않습니다.
- **다음 라운드:** 보상 → 상점 → 리스크 선택 → 출전 윷 편집입니다. 상점은 상품 3개와 말 강화부터 보여줍니다.

게임 영역의 `Space`: 던지기, `1~6`: 던질 윷 변경, `R`: 선택 윷 교체입니다. 버튼은 Tab·Enter로 조작합니다. 전투의 Esc는 연출 중에는 결과로 이동하고, 결과에서는 계속합니다.

## 읽어야 할 숫자

- **보유점수 · 말 합계:** 생존 미완주 말의 잠재 점수. 완주해야 실제 점수가 됩니다.
- **남은 필요 점수:** 목표에서 실제 완주 정산 점수를 뺀 값입니다.
- **HP·공격:** 기본 능력치 + weight 계수에 윷·특성·판 전체 배율을 적용합니다. HP가 0이거나 weight가 0이면 라운드에서 사망합니다.
- **속도:** 기본 1은 윷 결과 그대로입니다. 전진은 윷 이동 + 기본 속도 -1 + 말/판 전체 보너스입니다. 빽도는 -1 고정입니다.
- **재화·이번 이자·다음 기본 목표:** 지출과 저축, 다음 도전을 미리 비교하는 정보입니다. 보상 단계의 이자는 수령할 확정값입니다.

## 보스·특수칸·마스터

지름길 C와 완주 직전 G의 **수문장 2체**는 항상 있습니다. 리스크 픽과 라운드에 따라 일반 보스가 추가돼 총 2~5체가 됩니다. 픽에 따라 HP·공격·기믹·개수도 바뀝니다.

C는 최종 도착 칸이 일치할 때만 교전합니다. 경유하거나 옆 칸에 가도 싸우지 않습니다. 외곽·대각선은 정사각형 귀환 모서리 J에서 합류합니다. J는 출발 0과 같은 좌표의 별도 귀환 경로입니다. 아래로 J → G → END가 이어집니다. G는 모든 경로가 멈추는 완주 관문으로, 보스를 돌파하면 정산합니다. 지름길 수문장은 업힌 묶음의 선공을 강화하고, 완주 수문장은 HP 절반 이하 반격이 강해집니다.

게임 마스터는 별개로 특수칸과 판 전체 특성을 관리합니다. 칸에 **최종 도착**하면 weight·HP·속도의 메리트/디메리트를 줍니다. 기본 3턴마다 위치·개수·종류·판 전체 특성을 바꿉니다. 첫 3턴은 현재 판 전체 효과를 요약해 보이고 세부 내용은 접습니다. 이후 현재 효과·남은 턴은 기본 화면에, 다음 배치는 펼친 예고에 있습니다.

첫 라운드는 축복·회복 2칸과 고요한 판입니다. 둘째 라운드부터 작은 weight 손실과 이동·공격 보상을 소개합니다. 이후 더 다양한 디메리트·기믹을 사용합니다.

| 특성 부류 | 영향 |
|---|---|
| 초기 리스크 픽 | 가장 큰 메리트·디메리트. 목표·보스 수/능력치/기믹·보상 변경 |
| 구매 덱 카드 | 이익 중심. 구매·삭제·강화, 재화/슬롯 비용 |
| 마스터 판 전체 특성 | 초기 픽보다 변화는 작고 구매 카드보다 직접 디메리트는 큼 |

## 편집과 저장

**편집 모드**는 턴 진행을 멈춥니다. 대상 목록 또는 보드에서 개체를 고른 뒤 **변경 적용**을 누릅니다. 보드·말·보스·특수칸 드래그도 지원합니다.

| 대상 | 편집 |
|---|---|
| UI 프레임 | 패널 너비·글자 크기·강조색 |
| 보드 | 시각 좌표. 경로 연결은 유지 |
| 말 | weight·HP·기본 HP/공격·weight 계수·윷 배율·기본 속도/이동 보너스·배치 |
| 말 원형 | 현재 말 편집에서 ‘이후 라운드 원형에도 반영’을 선택 |
| 보스 | 주둔 칸·weight·HP·기본 능력치·계수·배율 |
| 라운드 | 목표·정산 점수·투척·교체·재화·리스크 위험도 |
| 마스터 | 갱신 주기·현재 판 전체 특성 |
| 특수칸 | 추가·삭제·위치·종류 |

**박싱 머신**에서 레이어를 표시/숨김하거나 고정 투척·확인용 장면을 열 수 있습니다. 장면 버튼은 별도 새 런으로 시작합니다. 화면을 숨겨도 규칙 효과는 유지됩니다.

장면 저장은 시드·카드·성장·손패·보스·마스터 계획·특수칸·배치·사건을 JSON으로 다운로드합니다. 불러오면 편집 모드에서 복원하고 이어서 플레이할 수 있습니다. 저장소 파일을 직접 덮어쓰지 않습니다. 1.4 이하의 장면 파일은 경로·규칙이 달라 거부합니다. 귀환 J는 출발 0의 좌표를 따릅니다. G·END는 아래쪽 별도 노드이며 좌표 Y는 7.3까지 편집할 수 있습니다.

## 사용자 확인 목록 — 실행하지 않음

이번 작업에서는 빌드·브라우저 실행·게임 플레이·자동/수동 테스트를 하지 않았습니다. 아래 항목은 사용자가 수행합니다.

| 확인 | 기대 결과 |
|---|---|
| 첫 3턴 체험 → 던지기 → 지름길 | 도→걸→모 표시, 1턴 자동 업기, 2턴만 갈림길 선택, HP 전투와 점수 증폭 |
| 바로 시작 → 던지기 | 설정 선택 없이 출전, 윷 4개 준비, 투척 뒤 추가 말 선택 없이 이동 |
| 19에서 도, J에서 도 / b4에서 도 / 화면 폭 변경 | 19→J와 b4→J가 정사각형 모서리로 연결, J 아래 G·END가 일정 간격, G 교전 후 완주 |
| 5·10·중앙에서 각각 던지기 / C의 생존 보스 재공격 | 서로 다른 남은 길만 2개 선택, 같은 길·빽도·재공격은 추가 선택 없음 |

| 두 수문장과 위험도 높은 픽 비교 | 수문장 유지, 일반 보스 수·HP·공격·기믹이 선택에 따라 변경 |

## 파일과 범위

- `index.html`: 기획서와 게임 임베딩, 직접 열기용 데이터 사본.
- `game-data.json`: 3종 특성·보스·마스터·특수칸·성장과 수식의 초깃값.
- `boxing-core.js`: 공통 점수·전투·턴말 예측/확정, 시드·덱·상점·성장.
- `boxing-game.js`: 실제 조작·HUD·연출·초반 노출·편집·장면 저장/복원.
- `design-view.js`: 기획서 표·보드·공통 코어 계산기.
- `boxing-game.css`: 박싱 레이어·전투·숫자 증폭·반응형 UI.

모든 수치는 미검증 초깃값입니다. 무한 모드·별도 막 증강·PvP·대규모 SRPG·Python/pico2d 이식과 실제 3·3·3 달성은 후속 범위입니다.
